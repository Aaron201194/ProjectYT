# ProjectYT
Youtube in Scratch

Welcome to ProjectYT! (Originally ScratchTube, I just thought this was a cooler name)

The main repository is for videos 25MB or smaller
(usually enough for a good 3-4 minutes at my export quality)

The releases page is for videos above 25MB and below the github cap
(for example a video at my export quality, a 2 hour long video would be about 315 MB)

See the wiki for anymore questions you have about ProjectYT.
